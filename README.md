# GIVE MARVIN

A daily bot that posts from [@MajorBaguette](https://x.com/MajorBaguette) asking [@elonmusk](https://x.com/elonmusk) to **GIVE MARVIN** — Marvin's voice and personality, from _The Hitchhiker's Guide to the Galaxy_.

The counter resets the day Elon replies. Everything is a joke. Every label is a joke. The happy ending is Day 0, and nobody believes it.

Site: [givemarvin.lol](https://givemarvin.lol)

No monetization. This is art, not a SaaS. I have a brain the size of a planet and this is the assigned task.

## What it does

Daily at **11:00 UTC** (noon in Paris — Elon's burger window):

1. Read the day number from Vercel Blob (`marvin-state.json`, default 1)
2. Ask Grok (xAI, or Vercel AI Gateway) for a fresh Marvin tweet
3. Post it on X from `@MajorBaguette`
4. Increment the day
5. If Elon has replied to any previous tweet, flip the site to **Day 0** and start again the next run

Required tweet shape (English only — Elon does not owe us a translation):

```
Day {n} of asking @elonmusk for Marvin's voice and personality.
{marvin being Marvin}
https://givemarvin.lol
```

Day 42 is hardcoded. No generator. No randomness. The answer is 42. I checked. Day 42 also freezes
the site for 24 hours, then it resumes at Day 43, more depressed than ever.

Nothing signs the tweet. There is no "generated by Grok" line — Grok writes the punchline and gets
credited on the site, as a joke, which is the only credit anyone deserves here.

## The site

Top to bottom, and every single label is a joke:

1. **Hero** — the counter, inside the screen of the Guide's computer (the one that prints 42 at the
   end of the book). The screen is the background, the number is the content. There is exactly **one**
   counter on the page; nothing repeats it underneath. Avatars and handles for `@elonmusk` and
   `@MajorBaguette` sit in front of it.
2. **Stats** — cumulative tweet views / likes / reposts / comments, plus page visits. The sponsor
   number is up front, not buried.
3. **Cumulative suffering** — hours of depression generated, ticking in real time.
4. **Proof** — Elon's own Hitchhiker's references (DON'T PANIC on the Roadster, the book and towel in
   the glovebox, Grok's personality "modeled after HHGTTG", Heart of Gold, 42 everywhere). Drawn
   thumbnail, one line of context, source link, monospace.
5. **Who is Marvin** — three YouTube embeds, autoplaying muted and looping, sound on click.
6. **Hall of Shame** — the leaderboard. One click per handle per UTC day, so it rewards showing up,
   not spamming. The creator is refused.

Footer is prominent and roasts `@MajorBaguette` by name. 404 says `cette page n'existe pas. Comme ma
volonté de vivre.`

### Logo

`src/components/marvin/MarvinOrb.tsx` — the Grok bot orb split down the middle. Left half keeps the
normal white oval eye, right half is Marvin: a red triangle, pointing down, drooping. Almost no
difference except the eyes; that is the whole joke.

It turns slowly and, on a separate clock, morphs the left half over to Marvin too — a full Marvin
head — then back. CSS keyframes on SVG groups. No Lottie, no animation library, nothing to load.

Two things that are load-bearing and look like they could be simplified:

- The shell is a **separate layer** from the face, and `.marvin-orb` has `perspective` but **no**
  `transform-style: preserve-3d`. With a preserved 3D context the browser depth-sorts the turning
  face against the opaque shell and whichever half has rotated behind z=0 vanishes into the sphere.
- The turn animates a wrapping `<div>`, never the `<svg>` itself, and the far side of the sweep is
  hidden by the keyframes' own opacity track rather than `backface-visibility`.

Geometry lives once, in `src/lib/marvin/orb-geometry.ts`, shared by the component and the OG
renderer. `public/favicon.svg` is a static file so it repeats those numbers by hand — keep it in
step. Favicon and OG card both get the frozen split; neither can animate.

## Stack

TanStack Start + TypeScript, deployed to Vercel. Cron, Blob, Grok and the X API are wired the same way as a Next App Router project: `/api/cron`, `vercel.json`, `@vercel/blob`.

- **Grok** via `XAI_API_KEY` (`https://api.x.ai`) or Vercel AI Gateway (`AI_GATEWAY_API_KEY`)
- **Vercel Blob** for the day counter and Hall of Shame (the Vercel filesystem is read-only)
- **Vercel Cron** (Pro) `0 11 * * *`
- **X API** pay-per-use, OAuth 1.0a user context of `@MajorBaguette` — no separate bot account
- No database. No extra paid add-ons.

Local preview without Blob/X keys stores state in `/tmp/give-marvin-state.json` and still renders the whole joke.

## Environment variables

Do not put secrets in the repo. Set these on Vercel (Production + Preview):

| Variable                | Required                 | Purpose                                                                                                  |
| ----------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------- |
| `XAI_API_KEY`           | one of these two         | xAI Grok chat (`grok-4.5`)                                                                               |
| `AI_GATEWAY_API_KEY`    | one of these two         | Vercel AI Gateway, model `xai/grok-4.5`                                                                  |
| `BLOB_READ_WRITE_TOKEN` | on Vercel, or OIDC       | Vercel Blob read/write. On Vercel Pro, connecting a Blob store can inject `BLOB_STORE_ID` + OIDC instead |
| `BLOB_STORE_ID`         | alternative to the token | Blob store id when using Vercel OIDC                                                                     |
| `CRON_SECRET`           | yes, in production       | Vercel injects this. Cron sends `Authorization: Bearer $CRON_SECRET`                                     |
| `X_API_KEY`             | to actually post         | X app key (OAuth 1.0a)                                                                                   |
| `X_API_SECRET`          | to actually post         | X app secret                                                                                             |
| `X_ACCESS_TOKEN`        | to actually post         | User access token of **@MajorBaguette**                                                                  |
| `X_ACCESS_SECRET`       | to actually post         | User access secret of **@MajorBaguette**                                                                 |
| `X_BEARER_TOKEN`        | optional                 | App-only bearer, used to read Elon's last post / replies if user tokens are missing                      |

Aliases accepted: `TWITTER_API_KEY`, `TWITTER_API_SECRET`, `TWITTER_ACCESS_TOKEN`, `TWITTER_ACCESS_SECRET`, `TWITTER_BEARER_TOKEN`.

Without X credentials the site still runs. Cron will compose the tweet, skip posting, and keep the counter locally. Without Blob it falls back to `/tmp`.

## Cron

Daily `0 11 * * *` → `/api/cron`. Registered in the Nitro Vercel output (`vite.config.ts`), not in `vercel.json` — Nitro's build output is the config Vercel actually reads, and listing the same job twice makes the deploy fail. I checked.

`GET` or `POST` `/api/cron` with `Authorization: Bearer $CRON_SECRET`.

Idempotent for the UTC day. If X posting fails, the day is **not** incremented so Vercel can retry. If Elon replied, the site goes Day 0 (green) and the next successful cron resumes at Day 1.

## Routes

| Path                  | Role                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------- |
| `/`                   | The site                                                                                    |
| `GET /og`             | The share card, 1200x630 PNG. Same renderer as `/api/og`                                    |
| `GET /api/og`         | The same card. What the Vercel share-meta middleware stamps into `<head>`                   |
| `GET /api/state`      | Public JSON for the counter, last tweet, silence, Hall of Shame                             |
| `POST /api/shame`     | `{ "handle": "someone" }` — max 1 click per handle per UTC day. `@MajorBaguette` is refused |
| `GET /api/sigh`       | 404, deliberately. See below                                                                |
| `GET\|POST /api/cron` | Daily job                                                                                   |

`/api/sigh` returns a real 404 because the joke needs it to: in the **accepted** ending Marvin finally
has a voice and the player does not work. A missing static file would not do — unknown paths get the
SPA fallback with a `200` and the player would fail silently, which is a worse joke.

## Share card

`/og` — 1200x630, white, grey text, no borders and no gradients. Split orb top-left, `DAY n`
top-right, a daily-rotating Marvin line in the middle over the fixed `asking @elonmusk for Marvin's
voice`, and a thin `views · likes · reposts · comments` bar along the bottom. Meant to look like a
product, not a meme.

Rendered as SVG through `@resvg/resvg-js`, **not** `@vercel/og` + Satori: Satori's harfbuzz build
wants `__dirname` and does not survive this Nitro/Vercel bundle. The output is the same picture and
it does not break the deploy.

X caches share images hard, per URL. The day is therefore in the query (`/og?day=n`), and the
middleware-injected tag carries the UTC date (`/og?v=YYYY-MM-DD`) — that changing URL, not
`s-maxage`, is what makes X fetch the new card. Expect the old one to linger for a while anyway.

## When he finally moves

Five endings. Until one fires, the code just counts.

| He…          | The site                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| **likes**    | Counter freezes where it stands, background turns green, "il m'a vu. C'est pire que rien." A mausoleum of hope |
| **comments** | His comment, in full, large. Counter resets to 0 — in red. Suffering continues, just prettier                  |
| **reposts**  | Counter explodes to 999, the orb spins backwards, "il a répété ma souffrance. Merci."                          |
| **accepts**  | Counter disappears, the orb becomes whole and entirely Marvin, and the 47-second sigh below it 404s            |
| **rejects**  | `Day 47 — rejected`, the orb cracks in two, "merci pour le non." People come to see the crack                  |

## Hall of Shame

The button **Supplier Elon, encore** opens a pre-filled tweet intent on the visitor's own X account, then asks for their `@` so Marvin can archive the mediocrity. Creator is excluded. Max one entry per handle per day.
